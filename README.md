# baconian-ciphers

**Experimental Results Data Dump** — a daily record of one day's progress on the
Baconian cipher work, presented three ways: a public-facing FAQ, a Reference column
of every external document used, and an unrestrained Technical Colophon.

Two strands, one shape:

- **Biliteral Cipher** — is the italic type in Shakespeare's First Folio one fount or two?
- **Word Cipher** — Orville Owen's method, the containing programme.

## Layout

```
/index.html              latest issue
/YYYY-MM-DD/index.html   permanent dated copy of each issue
/CNAME                   custom domain for GitHub Pages
```

Issues are **superseded, never deleted**. A link sent today still resolves next year.

## Build

None. Each issue is a single self-contained HTML file — no framework, no package
manager, no analytics, no cookies. The file in this repository is the file served.

## Publishing

GitHub Pages from `main`, custom domain in `CNAME`, TLS issued automatically.
DNS: A records to 185.199.108.153 / .109.153 / .110.153 / .111.153
